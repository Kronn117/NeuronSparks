# Neuro Sparks

Cyberpunk sci-fi mobile notes app built with Expo and React Native.

## Run & Operate

- `npm install` - install the Expo SDK 52 dependency set used by the PC source project.
- `npm run start` - start Expo.
- `npm run web` - start the web preview.
- `npm run android` - start Expo for Android.
- `npm run ios` - start Expo for iOS.
- `npm run lint` - lint the React Native source.

## Stack

- Expo SDK 52
- React 18.3.1
- React Native 0.76.9
- React Navigation stack navigation
- AsyncStorage local persistence
- JetBrains Mono bundled from `assets/fonts`

## Product

Neuro Sparks lets users create, edit, search, tag, pin, archive, export, restore, and delete notes with persistent local storage and cyberpunk sci-fi styling.
